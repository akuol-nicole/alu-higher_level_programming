===========================
How to Use 3-say_my_name.py
===========================

This module defines a function ``say_my_name(first_name, last_name="")``.

Usage
=====

``say_my_name(...)`` prints "My name is <first_name> <last_name>".

::

    >>> say_my_name = __import__('3-say_my_name').say_my_name
    >>> say_my_name("John", "Smith")
    My name is John Smith

::

    >>> say_my_name("Walter", "White")
    My name is Walter White

The parameter ``last_name`` is optional and defaults to an empty string. Note
that a trailing space is still printed after ``first_name``.

::

    >>> say_my_name("Bob")
    My name is Bob 

::

    >>> say_my_name("")
    My name is  

Invalid Names
=============

The parameters ``first_name`` and ``last_name`` must be strings. Otherwise,
a TypeError is raised.

::

    >>> say_my_name(12, "White")
    Traceback (most recent call last):
    TypeError: first_name must be a string

::

    >>> say_my_name("John", 12)
    Traceback (most recent call last):
    TypeError: last_name must be a string

::

    >>> say_my_name(None)
    Traceback (most recent call last):
    TypeError: first_name must be a string

::

    >>> say_my_name("John", None)
    Traceback (most recent call last):
    TypeError: last_name must be a string

::

    >>> say_my_name(["John"], ["Smith"])
    Traceback (most recent call last):
    TypeError: first_name must be a string

If neither parameter is a string, a TypeError is raised only for
``first_name``.

::

    >>> say_my_name(12, 34)
    Traceback (most recent call last):
    TypeError: first_name must be a string

Missing Arguments
=================

At least one argument (``first_name``) must be provided.

::

    >>> say_my_name()
    Traceback (most recent call last):
    TypeError: say_my_name() missing 1 required positional argument: 'first_name'
